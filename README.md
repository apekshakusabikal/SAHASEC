# SAHASEC
SAHASEC (Smart Assistive Health Alert System for Elderly Care) is an IoT-based healthcare monitoring system that tracks vital signs using sensors, displays real-time health data, and provides instant alerts through a dashboard and SMS notifications during abnormal readings.
🏥 SAHASEC – Smart Assistive Health Alert System for Elderly Care

📌 About the Project

SAHASEC (Smart Assistive Health Alert System for Elderly Care) is an IoT-based healthcare monitoring project developed during my TechXcelerate Summer Internship Program (SIP 2026).

The project focuses on supporting elderly care through real-time vital sign monitoring, a digital health dashboard, and instant alerts when abnormal readings are detected.

🎯 Project Objectives

- Monitor vital signs using health sensors.
- Display real-time health data through a dashboard.
- Identify abnormal health readings using predefined thresholds.
- Generate alerts and SMS notifications.
- Support remote health monitoring for elderly care.

🛠️ Technologies Used

- ESP32
- MAX30100 / MAX30102
- MLX90614
- HTML, CSS and JavaScript
- Firebase Realtime Database
- Python
- TextBee SMS API
